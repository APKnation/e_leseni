3. Get control number

5. My licences

Every reply is a number (or text, e.g. a business name when applying). Use 0 to go back. Applications, invoices and payments created here are real rows in the same database as the web app.

How the integration works

  1. A phone dials {{ serviceCode }} — the mobile operator opens a session and calls our gateway.
  2. The gateway POSTs sessionId, phoneNumber and text (the choices so far, joined by *) to /ussd/gateway/.
  3. The backend answers plain text starting with CON (keep the session open) or END (close it) — exactly what this simulator shows on the phone screen.
  4. To go live, point a real gateway at the same endpoint — no code changes.
